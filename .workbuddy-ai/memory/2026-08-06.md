# 2026-08-06

## Marketplace shadcn redesign + buyer session fix (coconoto_b2b2c)

### Session bug (root cause)
`api/auth.js` sets an httpOnly cookie on login + `MarketplaceAuthContext.refreshSession()` reads it,
but **login never wrote `buyerId`/`vendorId` to localStorage**. Dashboards and `Marketplace.tsx` read
localStorage → logged-in buyers were bounced from `/buyer-dashboard` and treated as guests in the
order modal (used `createOrder` instead of `createOrderWithBuyer`).

### Fix (Task #14)
- `src/context/MarketplaceAuthContext.tsx`: `refreshSession()` now syncs session → localStorage
  (`buyerId`/`vendorId`/`buyerName`/`vendorEmail`/`vendorBusinessName`/`buyerEmail`) on login, app
  load, and reload; `logout()` clears them. Single source of truth.
- `src/pages/vendor/Marketplace.tsx`: buyer identity now derived from `useMarketplaceAuth()` session
  (reactive) with localStorage fallback; passed into `OrderModal` so it re-renders once session resolves.

### shadcn foundation (Task #12/#13) — dependency-light, no radix/cva
- `@` alias added to `vite.config.ts` + `tsconfig.json`.
- Emerald shadcn CSS vars + `--sidebar-*` tokens added to `tailwind.config.js` + `src/index.css`.
- `src/lib/utils.ts` `cn()` helper.
- Primitives in `src/components/ui/`: button (with `asChild`), card, badge, input, label, textarea,
  separator, skeleton, avatar, tabs, dialog, sheet, dropdown-menu, table, select, sidebar-lite, toast.

### Redesigns (Tasks #15–#18)
- `Marketplace.tsx`: `ProductCard` → shadcn `Card`/`Badge`; `OrderModal` → shadcn `Dialog` + form
  primitives + success toast.
- `VendorDashboard.tsx`: full rewrite — `sidebar-lite` layout (desktop + mobile `Sheet`), `Card`
  product grid, `Table` orders, status `Badge`, `Dialog` product modal, context-aware logout, toasts.
- `BuyerDashboard.tsx`: full rewrite — same sidebar pattern, order `Card`s, profile view/edit with
  shadcn `Input`/`Label`, context-aware logout.
- `BuyerNavbar.tsx`: logout now calls `useMarketplaceAuth().logout()` (clears cookie + localStorage).
- `App.tsx`: wrapped in `ToastProvider`.
