## UI polish for Coconoto b2b2c

User asked to check the marketplace login UI (and identify what is missing), check the Blog Editor (vintage) for any needed changes, and modernize the Tweetit Mail UI. Other pages were left alone.

  - Added: forgot password link, show/hide password toggle, "Remember me", top brand bar, split-screen design with pitch panel, password focus + auto-prefill of remembered email, role="alert" error UI, password checklist, accessible aria-invalid labels.
- **`src/pages/vendor/VendorLogin.tsx`** — Marketplace vendor login
  - Added: forgot password link, show/hide password toggle, "Remember me", top brand bar, split-screen design with vendor pitch panel, cross-link to Buyer Login, modern loading button with spinner, role="alert" error UI.
- **`src/pages/TweetitLogin.tsx`** — Modernized
  - Glassmorphism card, animated gradient background blobs, password toggle, "Remember me", email prefill (from URL or saved), forgot-password via mailto, modern button with spinner, accessible form labels.
- **`src/pages/TweetitDashboard.tsx`** — Modernized
  - Backdrop-blurred header, gradient buttons (Compose, Manage Users, Logout), rounded chips, toast notifications (replacing alert()), emerald theme consistent with login, modern composer modal polish.
- **`src/components/blog/BlogEditor.tsx`** — Polished (vintage UI preserved)
  - Status pill (Draft/Published) at top, "Saved at HH:MM" indicator when clean, click-to-remove tag chips, word count alongside char count for description, keyboard shortcut hint chip, modern rounded save/publish buttons, gradient banner uploader with hover scale.

### Verification

- TypeScript: tsc shows no NEW errors in my edited files. Three pre-existing editor.js typing issues remain in BlogEditor.tsx (Marker/Embed have no .d.ts, Paragraph type mismatch with current package) — all present in the repo before this change.
- Vite build: All 1829 modules transformed cleanly. The only build error is a sandbox safety guard against bulk deletion of `dist/` (not a code problem).

### Decisions

- Skipped social login (Google etc.) — requires server config and is out of scope for "check what is missing".
- Kept the vintage/serif aesthetic on `VintageLogin` and the vendor brand color on VendorLogin rather than blending them — each visual identity is its own, matching the user's instruction to leave other pages alone.
- Replaced `alert()` in TweetitDashboard with a toast component for modern UX, kept all existing functionality identical.
